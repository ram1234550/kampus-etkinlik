# Kampüs Etkinlikleri

Süleyman Demirel Üniversitesi kampüsündeki seminer, atölye, konser ve spor etkinliklerini listeleyen, detaylarını gösteren ve yeni etkinlik eklemek için form sunan bir web uygulaması. Web Teknolojileri dersi kapsamında geliştirilmektedir.

## Sprint 1

Bu sprintte yalnızca HTML kullanılmıştır (CSS ve JavaScript yok).

## Sayfalar

- `index.html` — Ana sayfa: uygulamanın amacı ve yaklaşan etkinlikler
- `etkinlikler.html` — Tüm etkinliklerin listesi ve ayın programı
- `etkinlik-detay.html` — Bir etkinliğin afişi, tarihi, yeri ve açıklaması
- `etkinlik-ekle.html` — Yeni etkinlik ekleme formu
- `etkinlik-guncelle.html` — Mevcut etkinliği güncelleme formu
